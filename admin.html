⚡ SUPABASE REAL-TIME CLOUD DATABASE

Enables instant cross-device synchronization: registrations submitted on any mobile phone appear here live.

Offline Mode
📋 One-Time Supabase SQL Setup Script (Click to view & copy) ▼

1. Open your Supabase Dashboard (supabase.com) → SQL Editor → New query.

2. Paste the SQL below and click RUN:

-- 1. Create Registrations Table
CREATE TABLE IF NOT EXISTS registrations (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  reg_no TEXT NOT NULL,
  branch TEXT,
  year TEXT,
  phone TEXT,
  handle TEXT,
  pass TEXT DEFAULT 'All-Access Solo Pass',
  fee TEXT DEFAULT '100',
  screenshot TEXT,
  status TEXT DEFAULT 'PENDING',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Create Leaderboard Table
CREATE TABLE IF NOT EXISTS leaderboard (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  rank INT,
  handle TEXT NOT NULL,
  name TEXT NOT NULL,
  score INT DEFAULT 0,
  boss_dmg TEXT DEFAULT '0 DMG',
  streak TEXT DEFAULT '0 WINS',
  avatar TEXT,
  badge TEXT,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Create Event State Table (Boss HP, Broadcasts)
CREATE TABLE IF NOT EXISTS event_state (
  id TEXT PRIMARY KEY,
  boss_hp TEXT DEFAULT '78',
  broadcast_msg TEXT DEFAULT '',
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 4. Enable Row Level Security with Public Access for the tournament
ALTER TABLE registrations ENABLE ROW LEVEL SECURITY;
ALTER TABLE leaderboard ENABLE ROW LEVEL SECURITY;
ALTER TABLE event_state ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public all access on registrations" ON registrations FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Allow public all access on leaderboard" ON leaderboard FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Allow public all access on event_state" ON event_state FOR ALL USING (true) WITH CHECK (true);

-- 5. Enable Realtime Publications
ALTER PUBLICATION supabase_realtime ADD TABLE registrations;
ALTER PUBLICATION supabase_realtime ADD TABLE leaderboard;
ALTER PUBLICATION supabase_realtime ADD TABLE event_state;

3. Copy your Project URL and anon public key from Project Settings → API and paste above!

📊 GOOGLE SPREADSHEET LIVE SYNC

Connect your Google Sheet so all user registrations automatically append new rows in real time.

📖 How to create your Google Sheet Webhook in 30 seconds (Click to expand) ▼
  1. Create a new Google Sheet at sheets.new.
  2. In the top menu, click Extensions → Apps Script.
  3. Replace all code in the editor with the script below and click Save (💾):
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Timestamp", "Full Name", "Register No", "Branch", "Year", "Phone", "Fee", "Pass Tier", "Status", "Payment Screenshot"]);
  }
  sheet.appendRow([
    data.timestamp || new Date().toLocaleString(),
    data.name || "",
    data.regNo || "",
    data.branch || "",
    data.year || "",
    data.phone || "",
    data.fee || "100",
    data.pass || "All-Access Solo Pass",
    data.status || "PENDING",
    data.screenshot || "Uploaded"
  ]);
  return ContentService.createTextOutput(JSON.stringify({result: "success"})).setMimeType(ContentService.MimeType.JSON);
}
  1. Click Deploy → New deployment (top right).
  2. Select type: Web app.
  3. Set Execute as: Me, and Who has access: Anyone.
  4. Click Deploy, authorize permissions, and copy the Web app URL into the box above!
